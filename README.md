### How to Run the Programs

Open the project folder in VS Code and use the terminal commands below.

**Task 1 – File Processing Design Review**
```powershell
python Task01/mess_bill.py
```
Processes mess bill records, calculates the total and identifies invalid records.

**Task 2 – Biometric Attendance Processing**
```powershell
python Task02/attendance.py
```
Processes daily attendance files and generates attendance and damaged-record reports.

**Task 3 – Exception Handling Attendance Processor**
```powershell
python Task03/attendance_exceptions.py
```
Demonstrates exception handling, invalid-record handling and missing-file handling.

**Task 4 – File and Exception Forensics**
```powershell
python Task04/file_forensics.py
```
Demonstrates file-processing errors and corrected file-handling techniques.

**Task 5 – Attendance Processor Organisation**

Run the required versions separately:

```powershell
python Task05/Version1_SingleScript/attendance_single.py
python Task05/Version2_OneModule/main.py
python Task05/Version3_ThreeModules/main.py
python Task05/Version4_Package/main.py
```

These versions demonstrate a single script, one module, multiple modules and a Python package.

**Task 6 – College Fest Registration Package**
```powershell
python Task06/main.py
```
Processes department registration files, validates student details, removes duplicate registrations and generates the master list, event-wise participant lists, summary report and error log.
